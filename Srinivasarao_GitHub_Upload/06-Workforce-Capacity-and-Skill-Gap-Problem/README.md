# Workforce Capacity & Skill Gap Problem

**Domain:** HR

## Problem Statement

A company has sufficient employees on paper but continues to miss project deadlines because the required skills are not available at the right time. Develop an AI workforce intelligence system that maps employee skills against business requirements, identifies critical skill gaps, and recommends hiring, training and internal allocation strategies.

## 10-Step Solution Algorithm (AI Agent Workflow)

1. **Define:** Objective: meet project skill demand on time. Metrics: fill rate, bench time and project delays.
2. **Ingest:** Gather resumes, certifications, learning records, timesheets, allocations, leave plans and the project pipeline.
3. **Prepare:** Extract skills with an LLM into a standard taxonomy with proficiency levels; managers verify a sample.
4. **Analyze:** Build weekly skill demand and supply tables and compute gaps by skill, role and location.
5. **Validate:** Reconcile supply with actual utilization and leave data, and test the method on past staffing outcomes.
6. **Reason:** Planner Agent proposes options for each gap: reallocate, upskill, contract or hire, with cost and lead time.
7. **Decide:** Solve an assignment optimization that minimizes cost and delay; delivery and HR heads approve.
8. **Act:** Action Agent raises allocation requests, learning enrollments and hiring requisitions.
9. **Pilot:** Apply to one business unit for one quarter.
10. **Improve:** Track fill rate, time to staff and delays, and refresh the skills map monthly.

# Profitability Decline Investigation

**Domain:** Business Analytics

## Problem Statement

Company profitability has declined for three consecutive quarters, but individual departments report satisfactory performance. Develop an AI business analyst that integrates Marketing, HR, Operations and Finance data to identify cross-functional relationships responsible for the decline.

## 10-Step Solution Algorithm (AI Agent Workflow)

1. **Define:** Objective: explain the three-quarter profit decline. List cross-functional hypotheses to test.
2. **Ingest:** Gather the P&L, discounts and campaign costs, HR cost and attrition, operations costs, delays and returns.
3. **Prepare:** Align data by quarter, product and region and reconcile with Finance totals.
4. **Analyze:** Build a profit bridge (volume, price, mix, cost) and locate the largest decliners.
5. **Validate:** Test cross-functional links with lagged analysis and, where possible, difference-in-differences comparisons.
6. **Reason:** Analyst Agent (LLM) assembles the evidence into causal narratives and states the uncertainty.
7. **Decide:** Quantify the money impact of each chain; leaders approve joint initiatives with shared KPIs.
8. **Act:** Action Agent builds the monitoring dashboard and assigns tasks to owners.
9. **Pilot:** Run the initiatives for one quarter in selected units.
10. **Improve:** Review profit recovery every quarter.
